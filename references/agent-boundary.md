# Agent Boundary — Cross-Market Event Radar

## Agent 会做什么

- 从 PandaData 拉取 A 股定增、限售解禁、业绩预告、业绩快报与港美股分红、市场活动、股东大会、财务披露、IR 事件数据。
- 将跨市场事件标准化为统一 schema，标记数据完整性。
- 在同公司/时间窗内做事件关联（定增→解禁链、预告→快报一致性、分红→财报重叠、事件聚集）。
- 按「临近度 × 历史影响 × 数据完整性」对事件排序，输出研究候选清单。
- 生成每日事件看板与人读风险提示。
- 记录全部数据拉取日志，保证可复现、可审计。

## Agent 不会做什么

- 不生成任何无条件买卖指令或目标价。
- 不接入券商下单通道，不执行任何交易。
- 不承诺收益；历史影响权重仅是研究排序参考。
- 不用假设填充缺失数据；数据不足时明确标注 `insufficient_data` 或降低完整性分数。
- 不使用 PandaData 与用户授权数据之外的来源。

## 使用边界提示

所有产物（看板、清单、提示）都是研究与监控材料。使用者在做出任何决策前应自行验证证据，并结合合规要求。
